# Anime Compass 0.6B — ชุดใช้งานครบสำหรับเพื่อน

## วิธีเปิดบน Windows 64-bit

1. ติดตั้ง Python 3.11 แบบ 64-bit จาก https://www.python.org/downloads/ และเลือก Add Python to PATH
2. แตก ZIP ทั้งหมดลงโฟลเดอร์เดียว เช่น C:/AnimeCompass ห้ามเปิดแอปจากใน ZIP
3. ดับเบิลคลิก INSTALL.bat ครั้งแรก ต้องมีอินเทอร์เน็ตเพื่อติดตั้งไลบรารี
4. เมื่อติดตั้งสำเร็จ ดับเบิลคลิก START.bat แล้วเปิด http://127.0.0.1:8502/
5. เปิดหน้าต่างที่รันโปรแกรมไว้ตลอด เมื่อเลิกใช้ กด Ctrl+C ในหน้าต่างนั้น

ชุดนี้รวมโค้ด, CSV สะอาด 17,217 เรื่อง, เวกเตอร์ 0.6B, โมเดล embedding/reranker 0.6B
และโมเดลอธิบาย Qwen3.5-4B ที่ดาวน์โหลดครบแล้ว ไม่ต้องสร้าง embedding ใหม่หรือโหลดโมเดลซ้ำ
ชื่อไฟล์ที่ขึ้นต้นด้วยจุด เช่น .models และ .streamlit ต้องอยู่ครบ

## ทุกฟังก์ชัน

- TF-IDF ค้นคำอังกฤษ/ชื่อเรื่อง; embedding รองรับคำค้นไทยและอังกฤษ
- เลือกอนิเมะที่ชอบหลายเรื่อง พร้อมกรองประเภท แท็ก ปี ตอน คะแนน สถานะและสตูดิโอ
- เปิด Qwen Reranker เพื่อจัดอันดับซ้ำ (ค่าเริ่มต้นปิด)
- ดูเรื่องย่อ ภาพปก ลิงก์ MAL ดาวน์โหลด CSV และให้คะแนนประเมิน/ส่งออก
- กดอธิบายเพิ่มเติมด้วย Qwen3.5-4B ซึ่งใช้เฉพาะส่วนภาษา ไม่ต้องติดตั้ง Torchvision
- ดูข้อมูลล่าสุดผ่าน Jikan และ AniList สำรอง
- หน้าข้อมูลระบบและรายงาน cleansing

## เครื่องและอินเทอร์เน็ต

- ตัวติดตั้งนี้ใช้ CPU; ไม่ต้องมีการ์ดจอ NVIDIA
- แนะนำ RAM 32 GB และ SSD; โมเดลอธิบายส่วนภาษาใช้หน่วยความจำหลาย GB
  หากเปิดโปรแกรมอื่นมาก อาจโหลดไม่ได้หรือช้า เครื่องที่ RAM ต่ำไม่รับประกันว่าจะรันทุกโมเดลได้
- เตรียมพื้นที่ประมาณ 30 GB สำหรับ ZIP + ไฟล์ที่แตก และเพิ่มพื้นที่สำหรับ Python/ไลบรารี
  หลังแตกสำเร็จ สามารถย้าย ZIP ไปไดรฟ์อื่นเพื่อคืนพื้นที่ได้
- การค้นหา/จัดอันดับ/อธิบายใช้โมเดลบนเครื่องแบบ offline หลังติดตั้งแล้ว
- ภาพปก, ลิงก์ MAL และข้อมูลล่าสุดต้องใช้อินเทอร์เน็ต; API ภายนอกอาจจำกัดการใช้งานหรือหยุดบริการ
- Reranker และโมเดลอธิบายช้าบน CPU เครื่องต้นทางทดสอบ reranker ราว 66 วินาที
  และอธิบายโหลด+สร้างข้อความราว 84 วินาที แต่เวลาเครื่องเพื่อนอาจต่างกัน
- การแนะนำเป็นผลจากโมเดล ควรตรวจความเกี่ยวข้องและข้อความอธิบายกับเรื่องย่อ

## ถ้ามีปัญหา

- รัน VERIFY.py ด้วย .venv/Scripts/python.exe เพื่อตรวจไฟล์และการค้นหาพื้นฐาน (ไม่โหลดโมเดลใหญ่เข้า RAM)
- พอร์ต 8502 ถูกใช้: ปิดแอปเดิม หรือเปลี่ยน --server.port ใน START.bat เป็น 8503
- ติดตั้งไม่ครบ: อ่านข้อความ error ใน INSTALL.bat แล้วรันใหม่
- ห้ามนำ artifacts ของ 4B มาทับชุดนี้ เพราะข้อความใหม่และเวกเตอร์ต้องใช้โมเดลเดียวกัน

## ไฟล์ต้นทางและการตรวจสอบ

MODEL_NOTICES เก็บ model card/license จาก Hugging Face ของโมเดลทั้งสาม
MANIFEST.json เก็บรายการไฟล์ ขนาด และ SHA-256 ของไฟล์ทั้งหมดก่อน ZIP
ไม่มี virtual environment ของผู้สร้าง, token, ประวัติส่วนตัว หรือไฟล์ดาวน์โหลดค้างอยู่ในชุดส่งต่อ
